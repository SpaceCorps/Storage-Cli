Contact & Support

We welcome questions, bug reports, and pull requests for Storage CLI. Below are the official contact and support channels available to users, developers, and autonomous agent integrators.

Primary Support Channels

  • GitHub Issues: For reporting bugs and submitting feature requests, visit the issue tracker at github.com/SpaceCorps/Storage-Cli/issues.
  • GitHub Discussions: For architectural questions, agent workflows, and community integration patterns, join our discussions board at github.com/SpaceCorps/Storage-Cli/discussions.
  • SpaceCorps Organization: To explore our open-source tools and agentic software portfolio, visit github.com/SpaceCorps.

Security Inquiries

If you have discovered a potential security vulnerability within the CLI binary, credential handling routines, or secret store integration, please submit a report via GitHub Private Vulnerability Reporting on the repository page.
